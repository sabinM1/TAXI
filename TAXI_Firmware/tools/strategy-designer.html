Strategy file (StrategyData.h)
Import TAXI_Firmware/StrategyData.h, edit the openings, then export it back over the same file. There is no JSON — that C++ file is the only copy of the strategies. On export each opening also gets a handoff time (65 % of its total): after that point a close opponent outranks the committed move.
Dohyo & robot
Two calibrations, both measured on the real ring: how far it travels in 1 s at 100 % duty straight, and how many degrees it rotates in 1 s at full differential (left +100 / right −100).
Start position (active slot)
This start pose belongs to the active slot and is saved with it in StrategyData.h. Drag the robot on the ring to move it; drag the round handle to rotate. Type exact values in X / Y / Heading for a fully custom pose — the dropdown flips to Custom whenever the pose matches no preset. Heading 0° = up (toward the opponent), positive = clockwise. Openings that would otherwise turn now start already angled — set the heading here to match, so no time is spent pivoting.
